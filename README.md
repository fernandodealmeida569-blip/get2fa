# Get2FA: 2FA code generator that runs in your browser

**Live site: [get2fa.online](https://get2fa.online)** · [Português](https://get2fa.online/pt/) · [Español](https://get2fa.online/es/) · [Tiếng Việt](https://get2fa.online/vi/) · [Bahasa Indonesia](https://get2fa.online/id/) · [Deutsch](https://get2fa.online/de/) · [ไทย](https://get2fa.online/th/)

Paste a 2FA secret key, an `otpauth://` link or a QR code image and get the same 6-digit code your authenticator app shows. Everything is computed on your device with the browser's built-in Web Crypto API. **Your secret key is never sent to any server.**

## Features

- **Private by design.** TOTP is calculated locally (RFC 6238). No key, code or account name is uploaded, logged or stored.
- **Bulk mode.** Paste hundreds of keys or account lines such as `login|password|SECRET`; the key is detected in each line and you get a `line|code` list ready to copy.
- **Current and next code** with a countdown ring.
- **QR codes.** Paste, drop or upload a QR screenshot. Uses the native `BarcodeDetector` when available and the self-hosted [jsQR](https://github.com/cozmo/jsQR) library otherwise.
- **Google Authenticator export.** Reads `otpauth-migration://` export QR codes and shows every account with its key.
- **Private links.** `get2fa.online/#YOURKEY`: the part after `#` is never sent to the server.
- SHA-1, SHA-256 and SHA-512 · 6 or 8 digits · 30 or 60 seconds.
- Works offline once loaded, light and dark mode, available in English, Portuguese, Spanish, Vietnamese, Indonesian, German and Thai.

## Extra tools

- [2FA key & QR code generator](https://get2fa.online/2fa-key-generator): random TOTP secret, otpauth link and QR code (QR encoder in `site/assets/qrcode.js`, no dependencies).
- [2FA code checker](https://get2fa.online/check-2fa-code): tells you if a code matches and whether your device clock is off.
- [2FA QR code reader](https://get2fa.online/read-2fa-qr-code): extracts keys from QR images, including Google Authenticator exports.
- [Account line splitter](https://get2fa.online/account-line-splitter): split `user|pass|2FA` lines, pick columns and append the current 2FA code.

## Browser extension

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/comadcaaonchplkbblkbonkdonhpalcm)**

The `extension/` folder is a Chrome extension (Manifest V3): paste a key or right-click a page to scan its 2FA QR code. Keys you save stay in `chrome.storage.local`; nothing is sent anywhere. Permissions: `storage`, `activeTab`, `contextMenus`. See [extension/PRIVACY.md](extension/PRIVACY.md).

## Verify it yourself

1. Open [get2fa.online](https://get2fa.online) and your browser's developer tools (F12) → **Network** tab.
2. Paste a test key such as `JBSWY3DPEHPK3PXP`.
3. No request contains the key. The code is generated by [`site/assets/totp.js`](site/assets/totp.js), about 200 lines with no dependencies.
4. Check the response headers: the `Content-Security-Policy` only lets scripts connect to the site's own origin (see [`site/_headers`](site/_headers)), so the browser itself blocks sending data elsewhere.

## Run the tests

The TOTP engine is checked against the official test vectors from RFC 4226 and RFC 6238 (SHA-1, SHA-256, SHA-512):

```bash
node tests/totp.test.js
```

## Project structure

```
site/            static website, ready to deploy (Cloudflare Pages, Netlify, GitHub Pages…)
  assets/totp.js TOTP/HOTP engine, Base32, otpauth and Google Authenticator export parsing
  assets/app.js  user interface
  assets/qrcode.js QR encoder (byte mode, level M)
  assets/qrread.js / tools.js  QR reader and extra tools
  assets/jsQR.js QR decoder (third party, loaded only when needed)
build.py         generates the HTML pages in every language
i18n_base.py     interface texts (EN, PT)
lang_*.py        interface texts (ES, VI, ID, DE, TH)
content_*.py     tool pages and guides (ES, VI, ID, DE, TH)
new_articles.py  newer multilingual guides
split_tool.py    account line splitter page (all languages)
platform_guides.py, platform_guides_more.py   per-platform 2FA guides (vi, th, es, id, de)
alt_article.py   comparison guide (en, vi)
lang_fr.py … lang_km.py   home page only for 10 more languages
articles.py      the 2FA guides
tests/           test vectors
```

To regenerate the pages after editing texts: `python3 build.py`.

## Security notes

- A 2FA secret key is as sensitive as a password. Use online generators only on devices you trust, and keep your keys in a password manager or authenticator app.
- No analytics script reads the input field, and keys are never written to `localStorage`, cookies or the URL query string.
