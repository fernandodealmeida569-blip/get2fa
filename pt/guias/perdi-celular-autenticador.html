Perdi o celular com o autenticador: o que fazer

Perder o celular com os códigos 2FA assusta, mas quase sempre existe um caminho de volta. Siga estas opções na ordem.

Atualizado em 2026-11-19

1. Você guardou as chaves secretas?

Se você guardou as chaves de configuração (num gerenciador de senhas, numa nota ou impressas), ótimo: cole cada chave no Get2FA e você terá códigos funcionando na hora, em qualquer aparelho. Depois adicione as chaves num autenticador no celular novo.

2. A sincronização na nuvem estava ligada?

O Google Authenticator (com conta conectada), o Microsoft Authenticator, o 2FAS e outros fazem backup dos códigos. Instale o mesmo app no celular novo e entre com a mesma conta para restaurar.

3. Use os códigos de backup

A maioria dos sites oferece códigos de backup ou de recuperação de uso único ao ativar o 2FA (Google, Facebook, Instagram e GitHub oferecem). Cada código deixa você entrar uma vez. Depois de entrar, configure o 2FA de novo no celular novo.

4. Use outro método de 2FA

Se você também cadastrou SMS, chave de segurança, passkey ou outro aparelho confiável, use para entrar.

5. Peça a recuperação de conta

Em último caso, use a opção “Não consegue acessar seus códigos?” ou a recuperação de conta do site. Pode levar dias e geralmente exige comprovar identidade, então comece logo.

Depois de recuperar o acesso

  • Configure o 2FA de novo e, dessa vez, guarde cada chave nova num gerenciador de senhas.
  • Guarde os novos códigos de backup fora do celular.
  • Se o celular foi roubado, troque as senhas das contas importantes e remova o aparelho antigo das suas contas.
