How to use it

  1. Name itType the issuer (your app or site) and the account. They become the label people see in their authenticator.
  2. Scan or copyScan the QR code with Google Authenticator, Microsoft Authenticator, 2FAS or any TOTP app, or copy the otpauth:// link.
  3. Check the codeThe current code updates live, so you can confirm the app shows the same number.

What is an otpauth:// link?

It's the standard format authenticator apps read from a QR code: otpauth://totp/Issuer:account?secret=KEY&issuer=Issuer. Optional parameters set the algorithm, digits and period. Most services use SHA-1, 6 digits and 30 seconds, which are the defaults here.

Is it safe to generate keys online?

Keys are created with crypto.getRandomValues in your browser and nothing is uploaded. For production systems, generate secrets on your own server and store them encrypted; use this tool to test, prototype or set up personal accounts.

Which key length should I use?

160 bits (32 Base32 characters) is what RFC 4226 recommends and what most services use. 80 bits is the minimum some older apps accept; 256 bits works with modern apps.
