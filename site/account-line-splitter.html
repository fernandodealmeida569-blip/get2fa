Account line splitter (user|pass|2FA)

Paste account lines, pick the columns you need, change the separator and add the live 2FA code to each line. Nothing is uploaded.

Columns click to include or remove · 🔑 = 2FA key
Advanced settings
Lines are processed on your device and never uploaded. Codes refresh every few seconds while “add 2FA code” is on.

How to use it

  1. Paste the linesOne account per line, in any format: user|pass|2FA, email:pass, CSV…
  2. Pick the columnsClick the column chips or type the order you want, like 3,1.
  3. Copy or downloadChoose the output separator and, if you want, add the current 2FA code to each line.

What can it do?

  • Keep only some columns, for example just the 2FA keys or just the emails.
  • Reorder columns and convert between separators (|, :, ;, comma, tab).
  • Remove duplicate and empty lines.
  • Find the 2FA key in each line automatically and append the 6-digit code that works right now.

Privacy

Account lines often contain passwords. This tool runs entirely in your browser: nothing you paste is sent, logged or stored. Close the tab when you're done. Need the codes only? Use the 2FA code generator, which also accepts whole lines.
