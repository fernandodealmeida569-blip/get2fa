So erhältst du deinen 2FA-Code

  1. Geheimen Schlüssel findenBeim Aktivieren von 2FA zeigt die Website einen QR-Code und einen Textschlüssel (meist unter „Scannen nicht möglich?“). Bewahre ihn auf.
  2. Oben einfügenFüge den Schlüssel, den otpauth://-Link oder ein Bild des QR-Codes ein. Leerzeichen und Kleinbuchstaben sind egal.
  3. Code kopierenKlicke auf den Code, um ihn zu kopieren, und nutze ihn, bevor der Kreis abläuft. Alle 30 Sekunden erscheint ein neuer.

Ist es sicher, einen 2FA-Schlüssel auf einer Website einzufügen?

Ein geheimer 2FA-Schlüssel ist so sensibel wie ein Passwort: Wer ihn hat, kann deine Codes erzeugen. Deshalb rechnet Get2FA alles in deinem Browser mit dem Standardalgorithmus (RFC 6238) und sendet den Schlüssel nirgendwohin. Du kannst das prüfen: Öffne die Entwicklertools, wechsle zum Tab „Netzwerk“ und füge einen Schlüssel ein. Keine Anfrage enthält ihn.

Trotzdem ersetzt eine Website keine Authenticator-App. Für Konten, die du täglich nutzt, speichere den Schlüssel in Google Authenticator, Microsoft Authenticator, 2FAS, Aegis oder einem Passwortmanager, und nutze Get2FA an einem anderen Gerät, beim Handywechsel oder wenn du viele Konten verwaltest.

Wo du deinen geheimen 2FA-Schlüssel findest

Google

Google-Konto → Sicherheit → Bestätigung in zwei Schritten → Authenticator → Einrichten → „Scannen nicht möglich?“.

Facebook

Kontenübersicht → Passwort und Sicherheit → Zweistufige Authentifizierung → Authentifizierungs-App. Der Schlüssel steht unter dem QR-Code.

Instagram

Einstellungen → Kontenübersicht → Passwort und Sicherheit → Zweistufige Authentifizierung → Authentifizierungs-App → „Schlüssel kopieren“.

Microsoft

Sicherheit → Erweiterte Sicherheitsoptionen → Neue Anmeldemethode hinzufügen → Authentifizierungs-App → „Ich möchte eine andere App verwenden“ → „Bild kann nicht gescannt werden?“.

Discord, X/Twitter, Amazon, GitHub

Suche beim Einrichten einer Authenticator-App nach „Schlüssel manuell eingeben“ oder „Code kann nicht gescannt werden“. Dieser Text ist dein geheimer Schlüssel.

Häufige Fragen

Ist Get2FA kostenlos?

Ja. Kostenlos und ohne Anmeldung. Die Seite finanziert sich über Werbung, die nie im Generator selbst erscheint.

Ist der Code derselbe wie in Google Authenticator?

Ja. Jede App nach dem TOTP-Standard liefert für denselben Schlüssel zur selben Zeit denselben Code, darunter Google Authenticator, Microsoft Authenticator, Authy und 2FAS.

Warum wird mein Code abgelehnt?

Meist liegt es an der Geräteuhr. TOTP-Codes hängen von der genauen Uhrzeit ab, also aktiviere automatisches Datum und Uhrzeit. Prüfe auch, ob du den ganzen Schlüssel kopiert hast und ob die Website 8 Stellen oder ein 60-Sekunden-Intervall nutzt (siehe Erweiterte Einstellungen).

Speichert ihr meine Schlüssel?

Nein. Schlüssel existieren nur im Speicher dieses Tabs und verschwinden beim Schließen. Wir nutzen keine Cookies oder Speicher für Schlüssel; nur das Design und die Auto-Kopieren-Option werden auf deinem Gerät gemerkt.

Kann ich Codes für viele Konten gleichzeitig abrufen?

Ja. Füge einen Schlüssel pro Zeile ein oder ganze Zeilen wie konto|passwort|SCHLÜSSEL. Du erhältst für jede Zeile einen Code und eine Liste im Format Zeile|Code zum Kopieren.

Was ist ein geheimer 2FA-Schlüssel?

Ein zufälliger Code, meist 16–32 Zeichen aus A–Z und 2–7 (Base32), den eine Website beim Aktivieren der Zwei-Faktor-Authentifizierung mit deiner Authenticator-App teilt. Der QR-Code ist derselbe Schlüssel als Bild.

Ich habe mein Handy verloren. Kann Get2FA meine Codes wiederherstellen?

Nur wenn du den geheimen Schlüssel gespeichert hast. Get2FA kann keine Schlüssel von einem anderen Gerät lesen. Ohne Schlüssel nutze die Backup-Codes des Dienstes oder dessen Kontowiederherstellung.
