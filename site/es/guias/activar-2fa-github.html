Cómo activar el 2FA de GitHub con una app de autenticación

Una app de autenticación protege tu cuenta de GitHub mejor que los SMS. Aquí tienes cómo activarla, dónde está la clave secreta y cómo obtener el código cuando no tienes el móvil a mano.

Actualizado 2026-11-23

Paso a paso

  1. Inicia sesión en GitHub, pulsa tu foto de perfil y elige Settings.
  2. En la columna izquierda, entra en Password and authentication.
  3. Pulsa Enable two-factor authentication.
  4. GitHub muestra un código QR. Pulsa setup key para ver la clave en texto, cópiala y guárdala.
  5. Añade la clave a tu app de autenticación o pégala en Get2FA, y escribe el código de 6 dígitos.
  6. Descarga los recovery codes y confirma que los has guardado para terminar.

La interfaz de GitHub está en inglés, por eso los nombres de los botones se dejan tal cual. GitHub exige 2FA a las cuentas que contribuyen con código, y los recovery codes son la única forma de volver a entrar si pierdes la clave y el móvil.

Guarda una copia de la clave

Antes de escanear el código QR, busca la opción para ver la clave en texto y guárdala en tu gestor de contraseñas. Si pierdes o cambias de móvil, basta con pegar esa clave en Get2FA o en una app de autenticación nueva para recuperar tus códigos. No compartas la clave ni una captura del QR: quien la tenga puede generar tus códigos.

Usar el 2FA en varios dispositivos

La misma clave da el mismo código en cualquier dispositivo. Puedes añadirla a un segundo móvil o pegarla en Get2FA en el ordenador para obtener el código sin el teléfono.

Problemas habituales

  • El código no es válido: comprueba que la fecha y la hora del dispositivo estén en automático. Consulta por qué no funciona el código 2FA.
  • No encuentro la clave en texto: consulta dónde encontrar la clave secreta 2FA.
  • He perdido el móvil: consulta qué hacer si pierdes el móvil con el autenticador.
