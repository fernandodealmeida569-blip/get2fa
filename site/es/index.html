Cómo obtener tu código 2FA

  1. Encuentra tu clave secretaAl activar 2FA, el sitio muestra un código QR y una clave en texto (normalmente en “¿No puedes escanearlo?”). Guárdala.
  2. Pégala arribaPega la clave, el enlace otpauth:// o una imagen del código QR. Los espacios y las minúsculas no importan.
  3. Copia el códigoHaz clic en el código para copiarlo y úsalo antes de que se acabe el círculo. Cada 30 segundos aparece uno nuevo.

¿Es seguro pegar una clave 2FA en una web?

Una clave secreta 2FA es tan sensible como una contraseña: quien la tenga puede generar tus códigos. Por eso Get2FA hace todo el cálculo dentro de tu navegador, con el algoritmo estándar (RFC 6238), y nunca envía la clave a ninguna parte. Puedes comprobarlo: abre las herramientas de desarrollador, ve a la pestaña Red (Network) y pega una clave. Ninguna petición la contiene.

Aun así, una web no sustituye a una app de autenticación. Para las cuentas que usas a diario, guarda la clave en Google Authenticator, Microsoft Authenticator, 2FAS, Aegis o un gestor de contraseñas, y usa Get2FA cuando estés en otro dispositivo, cambiando de móvil o gestionando muchas cuentas.

Dónde encontrar tu clave secreta 2FA

Google

Cuenta de Google → Seguridad → Verificación en dos pasos → Authenticator → Configurar → “¿No puedes escanearlo?”.

Facebook

Centro de cuentas → Contraseña y seguridad → Autenticación en dos pasos → App de autenticación. La clave aparece bajo el código QR.

Instagram

Configuración → Centro de cuentas → Contraseña y seguridad → Autenticación en dos pasos → App de autenticación → “Copiar clave”.

Microsoft

Seguridad → Opciones de seguridad avanzadas → Agregar una nueva forma de iniciar sesión → App de autenticación → “Quiero usar otra app” → “No puedo escanear la imagen”.

Discord, X/Twitter, Amazon, GitHub

Al configurar una app de autenticación, busca “introducir clave manualmente” o “no puedo escanear el código”. Ese texto es tu clave secreta.

Preguntas frecuentes

¿Get2FA es gratis?

Sí. Es gratis y no necesita registro. El sitio se mantiene con anuncios, que nunca aparecen dentro del generador.

¿El código será igual al de Google Authenticator?

Sí. Toda app que sigue el estándar TOTP da el mismo código para la misma clave a la misma hora, incluidas Google Authenticator, Microsoft Authenticator, Authy y 2FAS.

¿Por qué no aceptan mi código?

La causa más común es la hora del dispositivo. Los códigos TOTP dependen de la hora exacta, así que activa la fecha y hora automáticas. Revisa también que copiaste la clave completa y que el sitio no use 8 dígitos o un periodo de 60 segundos (ver Configuración avanzada).

¿Guardáis mis claves?

No. Las claves solo existen en la memoria de esta pestaña y desaparecen al cerrarla. No usamos cookies ni almacenamiento para claves; solo el tema y la opción de copiado automático se recuerdan en tu dispositivo.

¿Puedo obtener códigos de muchas cuentas a la vez?

Sí. Pega una clave por línea, o líneas completas como usuario|contraseña|CLAVE. Obtendrás el código de cada una y una lista en formato línea|código para copiar de una vez.

¿Qué es una clave secreta 2FA?

Es un código aleatorio, normalmente de 16 a 32 letras A–Z y números 2–7 (Base32), que un sitio comparte con tu autenticador al activar la verificación en dos pasos. El código QR es esa misma clave en forma de imagen.

Perdí el móvil. ¿Get2FA puede recuperar mis códigos?

Solo si guardaste la clave secreta. Get2FA no puede leer claves de otro dispositivo. Si no tienes la clave, usa los códigos de respaldo que te dio el servicio o su proceso de recuperación de cuenta.
