Comment obtenir votre code 2FA

  1. Trouvez votre clé secrèteQuand vous activez la 2FA, le site affiche un QR code et une clé en texte (souvent sous « Impossible de scanner ? »). Conservez-la.
  2. Collez-la ci-dessusCollez la clé, le lien otpauth:// ou une image du QR code. Les espaces et les minuscules ne posent pas de problème.
  3. Copiez le codeCliquez sur le code pour le copier et utilisez-le avant la fin du cercle. Un nouveau code apparaît toutes les 30 secondes.

Est-il sûr de coller une clé 2FA sur un site web ?

Une clé secrète 2FA est aussi sensible qu'un mot de passe : quiconque la possède peut générer vos codes. C'est pourquoi Get2FA fait tout le calcul dans votre navigateur, avec l'algorithme standard (RFC 6238), et n'envoie jamais la clé nulle part. Vous pouvez le vérifier : ouvrez les outils de développement, onglet Réseau, puis collez une clé. Aucune requête ne la contient.

Un site web ne remplace pas pour autant une application d'authentification. Pour les comptes que vous utilisez tous les jours, gardez la clé dans Google Authenticator, Microsoft Authenticator, 2FAS, Aegis ou un gestionnaire de mots de passe, et utilisez Get2FA quand vous êtes sur un autre appareil, que vous changez de téléphone ou que vous gérez de nombreux comptes.

Où trouver votre clé secrète 2FA

Google

Compte Google → Sécurité → Validation en deux étapes → Authenticator → Configurer → « Impossible de scanner ? ».

Facebook

Espace Comptes → Mot de passe et sécurité → Authentification à deux facteurs → Application d'authentification. La clé s'affiche sous le QR code.

Instagram

Paramètres → Espace Comptes → Mot de passe et sécurité → Authentification à deux facteurs → Application d'authentification → « Copier la clé ».

Microsoft

Sécurité → Options de sécurité avancées → Ajouter une nouvelle méthode de connexion → Application d'authentification → « Je veux utiliser une autre application » → « Je ne peux pas scanner l'image ».

Discord, X/Twitter, Amazon, GitHub

Pendant la configuration d'une application d'authentification, cherchez « saisir la clé manuellement » ou « impossible de scanner le code ». Ce texte est votre clé secrète.

Guides 2FA

Questions fréquentes

Get2FA est-il gratuit ?

Oui. Il est gratuit et ne demande aucune inscription.

Le code sera-t-il le même que dans Google Authenticator ?

Oui. Toute application qui suit le standard TOTP donne le même code pour la même clé au même moment, y compris Google Authenticator, Microsoft Authenticator, Authy et 2FAS.

Pourquoi mon code est-il refusé ?

La cause la plus fréquente est l'heure de l'appareil. Les codes TOTP dépendent de l'heure exacte : activez la date et l'heure automatiques. Vérifiez aussi que la clé est complète et que le site n'utilise pas 8 chiffres ou une période de 60 secondes (voir Paramètres avancés).

Conservez-vous mes clés ?

Non. Les clés n'existent que dans la mémoire de cet onglet et disparaissent quand vous le fermez. Seuls le thème et l'option de copie automatique sont mémorisés sur votre appareil.

Puis-je obtenir les codes de plusieurs comptes à la fois ?

Oui. Collez une clé par ligne, ou des lignes complètes comme identifiant|motdepasse|CLÉ. Vous obtenez le code de chacune et une liste ligne|code à copier d'un coup.

Qu'est-ce qu'une clé secrète 2FA ?

C'est un code aléatoire, en général de 16 à 32 lettres A–Z et chiffres 2–7 (Base32), qu'un site partage avec votre application d'authentification quand vous activez la validation en deux étapes. Le QR code est cette même clé sous forme d'image.

J'ai perdu mon téléphone. Get2FA peut-il retrouver mes codes ?

Seulement si vous avez gardé la clé secrète. Get2FA ne peut pas lire les clés d'un autre appareil. Sans la clé, utilisez les codes de secours fournis par le service ou sa procédure de récupération de compte.
