2FA code not working? Here's how to fix it

When a site says your 2FA code is invalid, the cause is almost always one of these. Start with the first: it solves most cases.

Updated 2026-11-19

1. Your device's clock is off

TOTP codes are calculated from the current time. If your phone or computer clock is wrong by more than about 30 seconds, the code won't match. Turn on automatic date and time (and automatic time zone) in your device settings, then try a new code.

2. The code expired while you typed it

Each code lasts 30 seconds and some sites reject it right at the end. Wait for a fresh code. Get2FA shows the seconds left and the next code, so you can choose the right moment.

3. You're using the wrong key or account

If you set up 2FA more than once, only the last key is valid. Make sure the entry in your app belongs to the same account (look at the name and email) and that you copied the whole key without missing characters.

4. The site uses different settings

Almost every site uses 6 digits, 30 seconds and SHA-1. A few use 8 digits, 60 seconds or SHA-256. If the QR code has these settings, apps read them automatically. With a text key, set them in Get2FA's Advanced settings.

5. The key was typed wrong

Secret keys only use letters A–Z and numbers 2–7. The digits 0, 1, 8 and 9 never appear, so a “0” is really the letter O and a “1” is the letter I or L. Copy and paste instead of typing whenever you can.

6. The code was already used

Some sites accept each code only once. If you just used a code, wait for the next one.

7. 2FA was reset on the site

If you (or a support agent) turned 2FA off and on again, the old key no longer works. Use a backup code to sign in and set up the authenticator again.

Still locked out?

Use the backup or recovery codes the site gave you, or start the site's account recovery. See what to do if you lost your phone.
