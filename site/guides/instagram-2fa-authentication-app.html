How to turn on Instagram 2FA with an authentication app

An authentication app is the safest 2FA method on Instagram. Here's how to turn it on, where to find the setup key and how to use the same key on several devices.

Updated 2026-11-19

Before you start

  • You need the Instagram app for Android or iPhone. The authentication app method can only be turned on from the mobile app.
  • Install an authenticator app (Google Authenticator, Microsoft Authenticator, 2FAS, Aegis…) or keep Get2FA open.

Step by step

  1. Open Instagram and tap your profile picture in the bottom right.
  2. Tap the menu (three lines) in the top right.
  3. Tap Accounts Center, then Password and security.
  4. Tap Two-factor authentication and select your Instagram account.
  5. Choose Authentication app and tap Next.
  6. Tap Copy key (or view the QR code). Save this key in a safe place before going on.
  7. Add the key to your authenticator app, or paste it into Get2FA to see the code.
  8. Type the 6-digit code into Instagram and tap Next.

Instagram's key is usually 32 characters long. Spaces don't matter: Get2FA and most apps remove them automatically.

Using 2FA on more than one device

The same key works on every device you add it to, so a team member or a second phone can generate the same codes. In Instagram, other devices are added from the same Authentication app screen with Copy key or View QR code.

Save your backup codes

After turning on 2FA, Instagram offers one-time backup codes. They're different from the setup key: each one works only once and is meant for when you can't get a code. Save them together with the key.

Common problems

  • “The code isn't valid”: check that your device's date and time are set to automatic. See why 2FA codes don't work.
  • Option missing: update the Instagram app. Older versions show 2FA under Settings → Security.
