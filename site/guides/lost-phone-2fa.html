Lost your phone with the authenticator app? What to do

Losing the phone that holds your 2FA codes is stressful, but there's usually a way back in. Go through these options in order.

Updated 2026-11-19

Have your secret key? Get your code nowOpen the 2FA generator

1. Did you save the secret keys?

If you kept the setup keys (in a password manager, a note or a printout), you're in luck: paste each key into Get2FA and you'll have working codes immediately, on any device. Then add the keys to an authenticator on your new phone.

2. Was cloud sync on?

Google Authenticator (when signed in), Microsoft Authenticator, 2FAS and others can back up your codes. Install the same app on the new phone and sign in with the same account to restore them.

3. Use backup codes

Most sites give you one-time backup or recovery codes when you turn on 2FA (Google, Facebook, Instagram and GitHub all do). Each code gets you in once. After signing in, set up 2FA again on your new phone.

4. Use another 2FA method

If you also added SMS, a security key, a passkey or another trusted device, use it to sign in.

5. Start account recovery

As a last resort, use the site's “Can't access your codes?” or account recovery option. It can take days and usually needs proof of identity, so start early.

After you're back in

  • Set up 2FA again and, this time, save each new key in a password manager.
  • Save the new backup codes outside your phone.
  • If the phone was stolen, change the passwords of your important accounts and remove the old device from your accounts.
