How to use any authenticator app with your Microsoft account

You don't have to use Microsoft Authenticator. Microsoft accounts work with any TOTP app, including Google Authenticator, 2FAS and Get2FA. The trick is a small link during setup.

Updated 2026-11-23

Step by step

  1. Sign in at account.microsoft.com/security.
  2. Select Manage how I sign in (or Advanced security options).
  3. Choose Add a new way to sign in or verify, then Use an app.
  4. When Microsoft offers to install Microsoft Authenticator, select Set up a different Authenticator app / I want to use a different authenticator app.
  5. Microsoft shows a QR code. Use “I can't scan the bar code” to see the secret key and save it.
  6. Add the key to your app (or Get2FA) and type the code to confirm.
  7. Back in security settings, turn on Two-step verification if it isn't on yet.

Before you turn it on

  • Microsoft recommends having three pieces of security info (for example an app, a phone number and an email) so you don't lose access.
  • Some older apps and devices can't ask for a code. For those, Microsoft uses app passwords, created in the same security page.

Work or school accounts

For accounts managed by a company or school, setup happens at your organization's sign-in page and your administrator decides which apps are allowed.

Keep a copy of the key

Before you scan the QR code, look for the option to see the key as text and save it in your password manager. If your phone is lost or replaced, you can paste that key into Get2FA or a new authenticator app and get your codes back in seconds. Never share the key or a screenshot of the QR code: anyone who has it can generate your codes.
