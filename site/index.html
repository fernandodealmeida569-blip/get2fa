How to get your 2FA code

  1. Find your secret keyWhen you turn on 2FA, the site shows a QR code and a text key (often under “Can't scan it?”). Save that key.

Is it safe to paste a 2FA key into a website?

A 2FA secret key is as sensitive as a password: anyone who has it can generate your codes. That's why Get2FA does all the math inside your browser with the standard algorithm (RFC 6238) and never sends the key anywhere. You can check it yourself: open your browser's developer tools, go to the Network tab and paste a key. No request contains it.

Still, a website is not a replacement for an authenticator app. For accounts you use every day, keep the key in an app such as Google Authenticator, Microsoft Authenticator, 2FAS, Aegis or a password manager, and use Get2FA when you're on another device, setting up a new phone, or managing many accounts.

Where to find your 2FA secret key

Google

Google Account → Security → 2-Step Verification → Authenticator → Set up → “Can't scan it?”.

Facebook

Accounts Center → Password and security → Two-factor authentication → Authentication app. The key is shown below the QR code.

Instagram

Settings → Accounts Center → Password and security → Two-factor authentication → Authentication app → “Copy key”.

Microsoft

Security → Advanced security options → Add a sign-in method → Authenticator app → “I want to use a different app” → “Can't scan the image?”.

Discord, X/Twitter, Amazon, GitHub

When you set up an authenticator app, look for “enter key manually” or “can't scan the code”. That text is your secret key.

Frequently asked questions

Is Get2FA free?

Yes. It's free and needs no sign-up. The site is supported by ads, which never appear inside the generator.

Will the code be the same as in Google Authenticator?

Yes. Every app that follows the TOTP standard gives the same code for the same key at the same time, including Google Authenticator, Microsoft Authenticator, Authy and 2FAS.

Why is my code not accepted?

The most common reason is a wrong device clock. TOTP codes depend on the exact time, so turn on automatic date and time on your device. Also check that you copied the full key and that the site doesn't use 8 digits or a 60-second period (see Advanced settings).

Do you save my keys?

No. Keys exist only in this tab's memory and disappear when you close it. We don't use cookies or storage for keys; only your theme and auto-copy choice are remembered on your device.

Can I get codes for many accounts at once?

Yes. Paste one key per line, or full lines like login|password|SECRET. You'll get a code for each one plus a list in the format line|code that you can copy at once.

What is a 2FA secret key?

It's a random code, usually 16 to 32 letters A–Z and numbers 2–7 (Base32), that a website shares with your authenticator when you turn on two-factor authentication. The QR code is just this key in picture form.

I lost my phone. Can Get2FA recover my codes?

Only if you saved the secret key. Get2FA can't read keys from another device. If you don't have the key, use the backup codes the service gave you or its account recovery process.
