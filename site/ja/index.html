2FAキー、otpauth:// リンク、またはQRコードを貼り付けると、認証アプリに表示されるものと同じ6桁のコードが得られます。高速・無料で、計算はお使いの端末内だけで行われます。

2FAコードの取得方法

  1. シークレットキーを見つける2FAを有効にするとき、サイトはQRコードとテキストのキーを表示します（多くは「スキャンできない場合」の下）。これを保存しておきます。
  2. 上の欄に貼り付けるキー、otpauth:// リンク、またはQRコードの画像を貼り付けます。スペースや小文字が含まれていても問題ありません。
  3. コードをコピーするコードをクリックしてコピーし、円が消える前に使います。30秒ごとに新しいコードに変わります。

Get2FAの特長

設計段階からプライバシー重視コードはブラウザのWeb Cryptoで計算されます。キー、コード、アカウント名がアップロード、記録、保存されることはありません。
一括モード数百個のキーや ユーザー|パスワード|キー 形式の行を貼り付けられます。各行からキーを見つけ、そのままコピーできる一覧を作ります。
現在のコードと次のコード残り秒数と次のコードが見えるので、期限切れ直前のコードを入力せずに済みます。
QRコードとotpauthリンクQRのスクリーンショットをドラッグまたは貼り付けるか、otpauth:// リンクを貼り付けます。発行元、アカウント、桁数、周期を自動で読み取ります。
すばやく安全なリンクget2fa.online/ja/#あなたのキー をブックマークできます。# より後ろはブラウザ内にとどまり、サーバーには届きません。
どこでも使えるスマホでもPCでも、ライトでもダークでも。一度読み込めばオフラインでも動きます。SHA-1、SHA-256、SHA-512、6桁または8桁に対応。

ウェブサイトに2FAキーを貼り付けても安全ですか？

2FAのシークレットキーはパスワードと同じくらい重要で、持っている人は誰でもあなたのコードを生成できます。そのためGet2FAは、標準アルゴリズム（RFC 6238）による計算をすべてブラウザ内で行い、キーをどこにも送信しません。開発者ツールの「ネットワーク」タブを開いてキーを貼り付ければ、キーを含む通信がないことを確認できます。

ただし、ウェブサイトは認証アプリの代わりにはなりません。毎日使うアカウントのキーはGoogle Authenticator、Microsoft Authenticator、2FAS、Aegis、またはパスワードマネージャーに保存し、Get2FAは別の端末を使うとき、機種変更のとき、多数のアカウントを管理するときに使ってください。

2FAシークレットキーの見つけ方

Google

Googleアカウント → セキュリティ → 2段階認証プロセス → 認証システム → 設定 →「スキャンできない場合」。

Facebook

アカウントセンター → パスワードとセキュリティ → 二段階認証 → 認証アプリ。キーはQRコードの下に表示されます。

Instagram

設定 → アカウントセンター → パスワードとセキュリティ → 二段階認証 → 認証アプリ →「キーをコピー」。

Microsoft

セキュリティ → 高度なセキュリティオプション → サインイン方法の追加 → 認証アプリ →「別のアプリを使用する」→「画像をスキャンできません」。

Discord、X/Twitter、Amazon、GitHub

認証アプリの設定中に「キーを手動で入力」や「コードをスキャンできない」を探してください。そこに表示される文字列がシークレットキーです。

よくある質問

Get2FAは無料ですか？

はい。無料で、登録も不要です。

Google Authenticatorと同じコードになりますか？

はい。TOTP標準に従うアプリは、同じキーに対して同じ時刻に同じコードを出します。Google Authenticator、Microsoft Authenticator、Authy、2FASも同様です。

コードが拒否されるのはなぜですか？

最も多い原因は端末の時刻です。TOTPコードは正確な時刻に依存するため、日付と時刻の自動設定を有効にしてください。キーを最後までコピーしたか、サイトが8桁や60秒周期を使っていないかも確認してください（詳細設定）。

キーは保存されますか？

いいえ。キーはこのタブのメモリ内にだけ存在し、タブを閉じると消えます。端末に記憶されるのはテーマと自動コピーの設定だけです。

複数アカウントのコードを一度に取得できますか？

はい。1行に1つのキー、または ユーザー|パスワード|キー のような行を貼り付けてください。それぞれのコードと、まとめてコピーできる 行|コード の一覧が得られます。

2FAシークレットキーとは何ですか？

通常16〜32文字の、A〜Zと2〜7（Base32）からなるランダムな文字列です。二段階認証を有効にするとき、サイトが認証アプリと共有します。QRコードは同じキーを画像にしたものです。

スマホをなくしました。Get2FAでコードを復元できますか？

シークレットキーを保存してある場合だけ可能です。Get2FAは他の端末のキーを読み取れません。キーがない場合は、サービスが発行したバックアップコードか、アカウント復旧の手続きを使ってください。
