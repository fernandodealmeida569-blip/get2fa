2FA 코드 받는 방법

  1. 비밀 키 찾기2FA를 켤 때 사이트는 QR 코드와 텍스트 키를 보여줍니다(보통 “스캔할 수 없나요?” 아래). 이 키를 보관하세요.
  2. 위에 붙여넣기키, otpauth:// 링크 또는 QR 코드 이미지를 붙여넣습니다. 공백이나 소문자가 있어도 괜찮습니다.
  3. 코드 복사코드를 클릭해 복사하고 원이 다 줄어들기 전에 사용하세요. 30초마다 새 코드가 나옵니다.

Get2FA를 쓰는 이유

처음부터 비공개로 설계코드는 브라우저의 Web Crypto로 계산됩니다. 키, 코드, 계정 이름은 업로드되거나 기록되거나 저장되지 않습니다.
대량 모드수백 개의 키나 아이디|비밀번호|키 형식의 줄을 붙여넣으세요. 각 줄에서 키를 찾아 바로 복사할 수 있는 목록을 만듭니다.
현재 코드와 다음 코드남은 시간과 다음 코드를 보여 주므로 곧 만료될 코드를 입력하지 않아도 됩니다.
QR 코드와 otpauth 링크QR 스크린샷을 끌어다 놓거나 붙여넣고, otpauth:// 링크도 붙여넣을 수 있습니다. 발급자, 계정, 자릿수, 주기를 자동으로 읽습니다.
빠르고 안전한 링크get2fa.online/ko/#내키 를 북마크하세요. # 뒤의 내용은 브라우저에만 남고 서버에 전달되지 않습니다.
어디서나 작동휴대폰이든 PC든, 밝은 테마든 어두운 테마든. 한 번 불러오면 오프라인에서도 작동합니다. SHA-1, SHA-256, SHA-512, 6자리 또는 8자리 지원.

웹사이트에 2FA 키를 붙여넣어도 안전한가요?

2FA 비밀 키는 비밀번호만큼 민감합니다. 키를 가진 사람은 누구나 코드를 생성할 수 있습니다. 그래서 Get2FA는 표준 알고리즘(RFC 6238)으로 모든 계산을 브라우저 안에서 처리하고 키를 어디에도 보내지 않습니다. 개발자 도구의 네트워크 탭을 열고 키를 붙여넣어 보면 키가 담긴 요청이 없다는 것을 직접 확인할 수 있습니다.

그래도 웹사이트가 인증 앱을 대신할 수는 없습니다. 매일 쓰는 계정의 키는 Google Authenticator, Microsoft Authenticator, 2FAS, Aegis 또는 비밀번호 관리자에 보관하고, Get2FA는 다른 기기를 쓸 때, 휴대폰을 바꿀 때, 많은 계정을 관리할 때 사용하세요.

2FA 비밀 키를 찾는 곳

Google

Google 계정 → 보안 → 2단계 인증 → OTP 앱 → 설정 → “스캔할 수 없나요?”.

Facebook

계정 센터 → 비밀번호 및 보안 → 2단계 인증 → 인증 앱. 키는 QR 코드 아래에 표시됩니다.

Instagram

설정 → 계정 센터 → 비밀번호 및 보안 → 2단계 인증 → 인증 앱 → “키 복사”.

Microsoft

보안 → 고급 보안 옵션 → 새 로그인 방법 추가 → 인증 앱 → “다른 앱을 사용하겠습니다” → “이미지를 스캔할 수 없습니다”.

Discord, X/Twitter, Amazon, GitHub

인증 앱을 설정할 때 “키 직접 입력” 또는 “코드를 스캔할 수 없음”을 찾으세요. 거기에 나오는 문자열이 비밀 키입니다.

자주 묻는 질문

Get2FA는 무료인가요?

네. 무료이며 가입이 필요 없습니다.

Google Authenticator와 같은 코드가 나오나요?

네. TOTP 표준을 따르는 앱은 같은 키에 대해 같은 시각에 같은 코드를 냅니다. Google Authenticator, Microsoft Authenticator, Authy, 2FAS 모두 같습니다.

코드가 거부되는 이유는 무엇인가요?

가장 흔한 원인은 기기 시간입니다. TOTP 코드는 정확한 시간에 의존하므로 날짜와 시간 자동 설정을 켜세요. 키를 끝까지 복사했는지, 사이트가 8자리나 60초 주기를 쓰지 않는지도 확인하세요(고급 설정).

제 키를 저장하나요?

아니요. 키는 이 탭의 메모리에만 있고 탭을 닫으면 사라집니다. 기기에는 테마와 자동 복사 설정만 기억됩니다.

여러 계정의 코드를 한 번에 받을 수 있나요?

네. 한 줄에 키 하나, 또는 아이디|비밀번호|키 형식의 줄을 붙여넣으세요. 각 줄의 코드와 한 번에 복사할 수 있는 줄|코드 목록을 받습니다.

2FA 비밀 키란 무엇인가요?

보통 16~32자의 A–Z와 2–7(Base32)로 이루어진 임의의 문자열입니다. 2단계 인증을 켤 때 사이트가 인증 앱과 공유합니다. QR 코드는 같은 키를 이미지로 만든 것입니다.

휴대폰을 잃어버렸습니다. Get2FA로 코드를 복구할 수 있나요?

비밀 키를 보관해 둔 경우에만 가능합니다. Get2FA는 다른 기기의 키를 읽을 수 없습니다. 키가 없다면 서비스에서 받은 백업 코드나 계정 복구 절차를 이용하세요.
