Código 2FA não funciona? Veja como resolver

Quando o site diz que o código 2FA é inválido, a causa quase sempre é uma destas. Comece pela primeira: ela resolve a maioria dos casos.

1. O relógio do aparelho está errado

Os códigos TOTP são calculados a partir do horário. Se o relógio do celular ou do computador estiver errado em mais de uns 30 segundos, o código não bate. Ative data e hora automáticas (e fuso horário automático) nas configurações e tente um código novo.

2. O código expirou enquanto você digitava

Cada código dura 30 segundos e alguns sites recusam bem no final. Espere um código novo. O Get2FA mostra os segundos restantes e o próximo código, para você escolher o momento certo.

3. Chave ou conta errada

Se você configurou o 2FA mais de uma vez, só a última chave vale. Confira se a entrada no app é da mesma conta (veja nome e e-mail) e se você copiou a chave inteira, sem faltar caractere.

4. O site usa outras configurações

Quase todo site usa 6 dígitos, 30 segundos e SHA-1. Alguns usam 8 dígitos, 60 segundos ou SHA-256. Se o QR code tiver essas configurações, os apps leem sozinhos. Com chave em texto, ajuste nas Configurações avançadas do Get2FA.

5. A chave foi digitada errada

Chaves secretas só usam letras de A a Z e números de 2 a 7. Os números 0, 1, 8 e 9 nunca aparecem, então um “0” na verdade é a letra O e um “1” é a letra I ou L. Sempre que puder, copie e cole em vez de digitar.

6. O código já foi usado

Alguns sites aceitam cada código uma única vez. Se você acabou de usar um, espere o próximo.

7. O 2FA foi redefinido no site

Se você (ou o suporte) desativou e ativou o 2FA de novo, a chave antiga não funciona mais. Use um código de backup para entrar e configure o autenticador outra vez.

Ainda sem acesso?

Use os códigos de backup ou de recuperação que o site forneceu, ou inicie a recuperação de conta do site. Veja o que fazer se perdeu o celular.
