Como ativar o 2FA do GitHub com app TOTP

O GitHub exige 2FA de todos que contribuem com código. Ele funciona com qualquer app TOTP e mostra exatamente as configurações que usa, então é um dos serviços mais fáceis de configurar.

Passo a passo

  1. Clique na sua foto de perfil → Settings.
  2. Na seção Access, abra Password and authentication.
  3. Clique em Enable two-factor authentication.
  4. Abaixo do QR code, clique em setup key para ver a chave TOTP. Guarde.
  5. Adicione a chave no seu app TOTP (ou no Get2FA) e digite o código em Verify the code from the app.
  6. Baixe os recovery codes (códigos de recuperação), guarde em lugar seguro e clique em I have saved my recovery codes.

As configurações que o GitHub usa

Para configurar um app manualmente, a documentação do GitHub informa: tipo TOTP, emissor GitHub, rótulo GitHub:seu-usuario, algoritmo SHA1, 6 dígitos e período de 30 segundos. São os padrões do Get2FA.

Mais de um aparelho

Para usar o 2FA em vários aparelhos, escaneie o QR code com todos durante a configuração, ou guarde a chave e adicione depois. Se o 2FA já estiver ativo, é preciso reconfigurar o app TOTP nas configurações de segurança para ver uma chave nova.

Proteção extra

Depois do app TOTP, dá para adicionar chave de segurança, passkey ou o GitHub Mobile como métodos extras, para não perder o acesso se um aparelho sumir.

Guarde uma cópia da chave

Antes de escanear o QR code, procure a opção de ver a chave em texto e guarde num gerenciador de senhas. Se o celular for perdido ou trocado, basta colar essa chave no Get2FA ou num app autenticador novo para ter os códigos de volta. Nunca compartilhe a chave nem prints do QR code: quem tem a chave consegue gerar seus códigos.
