Como pegar seu código 2FA

  1. Encontre sua chave secretaQuando você ativa o 2FA, o site mostra um QR code e uma chave em texto (geralmente em “Não consegue escanear?”). Guarde essa chave.
  2. Cole aqui em cimaCole a chave, o link otpauth:// ou uma imagem do QR code. Espaços e letras minúsculas não tem problema.
  3. Copie o códigoClique no código para copiar e use antes do círculo zerar. Um novo código aparece a cada 30 segundos.

É seguro colar uma chave 2FA num site?

A chave secreta do 2FA é tão sensível quanto uma senha: quem tem a chave consegue gerar seus códigos. Por isso o Get2FA faz todo o cálculo dentro do seu navegador, com o algoritmo padrão (RFC 6238), e nunca envia a chave para lugar nenhum. Você mesmo pode conferir: abra as ferramentas de desenvolvedor do navegador, vá na aba Rede (Network) e cole uma chave. Nenhuma requisição contém a chave.

Mesmo assim, um site não substitui um app autenticador. Para as contas que você usa todo dia, guarde a chave num app como Google Authenticator, Microsoft Authenticator, 2FAS, Aegis ou num gerenciador de senhas, e use o Get2FA quando estiver em outro aparelho, trocando de celular ou gerenciando muitas contas.

Onde encontrar sua chave secreta 2FA

Google

Conta do Google → Segurança → Verificação em duas etapas → Authenticator → Configurar → “Não consegue ler o código?”.

Facebook

Central de Contas → Senha e segurança → Autenticação de dois fatores → App de autenticação. A chave aparece abaixo do QR code.

Instagram

Configurações → Central de Contas → Senha e segurança → Autenticação de dois fatores → App de autenticação → “Copiar chave”.

Microsoft

Segurança → Opções de segurança avançadas → Adicionar uma nova forma de entrar → App autenticador → “Quero usar outro app” → “Não consegue ler a imagem?”.

Discord, X/Twitter, Amazon, GitHub

Ao configurar um app autenticador, procure “inserir chave manualmente” ou “não consegue escanear”. Esse texto é a sua chave secreta.

Perguntas frequentes

O Get2FA é grátis?

Sim. É grátis e não precisa de cadastro. O site é mantido por anúncios, que nunca aparecem dentro do gerador.

O código vai ser igual ao do Google Authenticator?

Sim. Todo app que segue o padrão TOTP gera o mesmo código para a mesma chave no mesmo horário, incluindo Google Authenticator, Microsoft Authenticator, Authy e 2FAS.

Por que meu código não é aceito?

O motivo mais comum é o relógio do aparelho errado. Os códigos TOTP dependem do horário exato, então ative data e hora automáticas. Confira também se copiou a chave inteira e se o site não usa 8 dígitos ou período de 60 segundos (veja Configurações avançadas).

Vocês salvam minhas chaves?

Não. As chaves existem só na memória desta aba e somem quando você fecha. Não usamos cookies nem armazenamento para chaves; só o tema e a opção de copiar automaticamente ficam salvos no seu aparelho.

Dá pra pegar códigos de várias contas de uma vez?

Sim. Cole uma chave por linha, ou linhas completas como login|senha|CHAVE. Você recebe o código de cada uma e uma lista no formato linha|código para copiar de uma vez.

O que é a chave secreta do 2FA?

É um código aleatório, normalmente com 16 a 32 letras de A a Z e números de 2 a 7 (Base32), que o site compartilha com o seu autenticador quando você ativa a verificação em duas etapas. O QR code é só essa chave em forma de imagem.

Perdi meu celular. O Get2FA recupera meus códigos?

Só se você tiver guardado a chave secreta. O Get2FA não consegue ler chaves de outro aparelho. Se você não tem a chave, use os códigos de backup que o serviço forneceu ou o processo de recuperação de conta.
