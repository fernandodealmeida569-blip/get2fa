Separador de linhas de contas (login|senha|2FA)

Cole as linhas das contas, escolha as colunas, troque o separador e adicione o código 2FA ao vivo em cada linha. Nada é enviado.

Colunas clique para incluir ou remover · 🔑 = chave 2FA
Configurações avançadas
As linhas são processadas no seu aparelho e nunca são enviadas. Com “código 2FA” ligado, os códigos se atualizam a cada poucos segundos.

Como usar

  1. Cole as linhasUma conta por linha, em qualquer formato: login|senha|2FA, email:senha, CSV…
  2. Escolha as colunasClique nas colunas ou digite a ordem desejada, como 3,1.
  3. Copie ou baixeEscolha o separador de saída e, se quiser, adicione o código 2FA atual em cada linha.

O que dá para fazer?

  • Manter só algumas colunas, por exemplo só as chaves 2FA ou só os e-mails.
  • Reordenar colunas e converter entre separadores (|, :, ;, vírgula, tab).
  • Remover linhas duplicadas e vazias.
  • Encontrar a chave 2FA em cada linha automaticamente e acrescentar o código de 6 dígitos válido agora.

Privacidade

Linhas de contas costumam ter senhas. Esta ferramenta roda inteira no seu navegador: nada do que você cola é enviado, registrado ou guardado. Feche a aba ao terminar. Só precisa dos códigos? Use o gerador de código 2FA, que também aceita linhas inteiras.
