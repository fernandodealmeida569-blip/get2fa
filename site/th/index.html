รับรหัส 2FA จากคีย์ลับ

วางคีย์ 2FA ลิงก์ otpauth:// หรือคิวอาร์โค้ด แล้วรับรหัส 6 หลักเดียวกับที่แอปยืนยันตัวตนแสดง รวดเร็ว ฟรี และคำนวณบนอุปกรณ์ของคุณเท่านั้น

คีย์ไม่ออกจากอุปกรณ์ของคุณใส่หลายคีย์พร้อมกันได้ใช้งานออฟไลน์ได้
เคล็ดลับ: วางหรือลากภาพหน้าจอคิวอาร์โค้ดลงบนหน้านี้ได้เลย รองรับคิวอาร์ส่งออกจาก Google Authenticator ด้วย
คัดลอกลิงก์แล้ว คีย์อยู่หลังเครื่องหมาย # ซึ่งเบราว์เซอร์ไม่ส่งไปยังเซิร์ฟเวอร์ แต่ใครที่ได้ลิงก์นี้จะสร้างรหัสของคุณได้

เครื่องมือ 2FA ฟรีอื่นๆ

สร้างคีย์และคิวอาร์สร้างคีย์ 2FA แบบสุ่มและคิวอาร์โค้ดสำหรับแอปยืนยันตัวตนทุกตัวเปิด →เช็กรหัส 2FAดูว่ารหัสตรงกับคีย์ไหม และนาฬิกาอุปกรณ์คลาดเคลื่อนหรือเปล่าเปิด →อ่านคิวอาร์ 2FAดึงคีย์ลับจากคิวอาร์ 2FA ทุกแบบ รวมถึงคิวอาร์ส่งออกของ Google Authenticatorเปิด →แยกข้อมูลบัญชีแยกบรรทัด user|pass|2FA เลือกคอลัมน์ และเพิ่มรหัส 2FA ปัจจุบันเปิด →
Get2FA สำหรับ Chrome: รับรหัสได้ในคลิกเดียว และสแกนคิวอาร์ 2FA ด้วยการคลิกขวาเพิ่มใน Chrome

วิธีรับรหัส 2FA

  1. หาคีย์ลับตอนเปิดใช้ 2FA เว็บไซต์จะแสดงคิวอาร์โค้ดและคีย์แบบข้อความ (มักอยู่ที่ “สแกนไม่ได้ใช่ไหม”) ให้เก็บคีย์นั้นไว้
  2. วางด้านบนวางคีย์ ลิงก์ otpauth:// หรือรูปคิวอาร์โค้ด ช่องว่างและตัวพิมพ์เล็กไม่มีผล
  3. คัดลอกรหัสคลิกที่รหัสเพื่อคัดลอก แล้วใช้ก่อนวงกลมหมดเวลา ทุก 30 วินาทีจะมีรหัสใหม่

ทำไมต้อง Get2FA

ความเป็นส่วนตัวมาก่อนรหัสคำนวณด้วย Web Crypto ของเบราว์เซอร์ ไม่มีการอัปโหลด บันทึก หรือเก็บคีย์ รหัส หรือชื่อบัญชี
โหมดหลายบัญชีวางคีย์หลายร้อยรายการ หรือบรรทัดแบบ บัญชี|รหัสผ่าน|คีย์ ระบบจะหาคีย์ในแต่ละบรรทัดและให้รายการพร้อมคัดลอก
รหัสปัจจุบันและรหัสถัดไปเห็นเวลาที่เหลือและรหัสถัดไป จะได้ไม่พิมพ์รหัสที่กำลังจะหมดอายุ
คิวอาร์โค้ดและลิงก์ otpauthลากหรือวางภาพหน้าจอคิวอาร์ หรือวางลิงก์ otpauth:// ระบบอ่านผู้ให้บริการ บัญชี จำนวนหลัก และช่วงเวลาให้อัตโนมัติ
ลิงก์ด่วนแบบส่วนตัวบันทึก get2fa.online/th/#คีย์ของคุณ ไว้ในบุ๊กมาร์ก ส่วนหลัง # อยู่ในเบราว์เซอร์และไม่ถึงเซิร์ฟเวอร์ของเรา
ใช้ได้ทุกที่มือถือหรือคอมพิวเตอร์ โหมดสว่างหรือมืด และใช้ออฟไลน์ได้หลังโหลดแล้ว รองรับ SHA-1, SHA-256, SHA-512, 6 หรือ 8 หลัก

วางคีย์ 2FA บนเว็บไซต์ปลอดภัยไหม?

คีย์ลับ 2FA สำคัญพอๆ กับรหัสผ่าน ใครมีคีย์ก็สร้างรหัสของคุณได้ Get2FA จึงคำนวณทั้งหมดในเบราว์เซอร์ของคุณด้วยอัลกอริทึมมาตรฐาน (RFC 6238) และไม่ส่งคีย์ไปที่ไหนเลย คุณตรวจสอบเองได้: เปิดเครื่องมือนักพัฒนา ไปที่แท็บ Network แล้ววางคีย์ จะไม่มีคำขอใดที่มีคีย์นั้น

อย่างไรก็ตาม เว็บไซต์ไม่ได้แทนแอปยืนยันตัวตน สำหรับบัญชีที่ใช้ทุกวัน ให้เก็บคีย์ไว้ใน Google Authenticator, Microsoft Authenticator, 2FAS, Aegis หรือโปรแกรมจัดการรหัสผ่าน และใช้ Get2FA เมื่ออยู่บนอุปกรณ์อื่น ตอนเปลี่ยนมือถือ หรือเมื่อดูแลหลายบัญชี

หาคีย์ลับ 2FA ได้ที่ไหน

Google

บัญชี Google → ความปลอดภัย → การยืนยันแบบ 2 ขั้นตอน → Authenticator → ตั้งค่า → “สแกนไม่ได้ใช่ไหม”

Facebook

ศูนย์บัญชี → รหัสผ่านและความปลอดภัย → การยืนยันตัวตนแบบสองขั้นตอน → แอปยืนยันตัวตน คีย์จะอยู่ใต้คิวอาร์โค้ด

Instagram

การตั้งค่า → ศูนย์บัญชี → รหัสผ่านและความปลอดภัย → การยืนยันตัวตนแบบสองขั้นตอน → แอปยืนยันตัวตน → “คัดลอกคีย์”

Microsoft

ความปลอดภัย → ตัวเลือกความปลอดภัยขั้นสูง → เพิ่มวิธีลงชื่อเข้าใช้ใหม่ → แอปตัวรับรองความถูกต้อง → “ใช้แอปอื่น” → “สแกนรูปภาพไม่ได้ใช่ไหม”

Discord, X/Twitter, Amazon, GitHub

ตอนตั้งค่าแอปยืนยันตัวตน ให้มองหา “ป้อนคีย์ด้วยตนเอง” หรือ “สแกนโค้ดไม่ได้” ข้อความนั้นคือคีย์ลับของคุณ

คู่มือ 2FA

2FA คืออะไร (การยืนยันตัวตนแบบสองปัจจัย)?2FA คืออะไร ทำงานอย่างไร มีกี่แบบ (SMS แอปยืนยันตัวตน คีย์ความปลอดภัย) และทำไมช่วยปกป้องบัญชีของคุณ รวมถึงรหัส 2FA คืออะไรอ่านคู่มือ →หาคีย์ลับ 2FA ได้ที่ไหนคีย์ลับ 2FA คืออะไร และหาได้ที่ไหนตอนเปิดใช้การยืนยันแบบ 2 ขั้นตอนบน Google, Facebook, Instagram, Microsoft และเว็บอื่นๆอ่านคู่มือ →รหัส 2FA ใช้ไม่ได้? วิธีแก้รหัสจากแอปยืนยันตัวตนถูกปฏิเสธตลอด? รู้สาเหตุที่พบบ่อย ตั้งแต่นาฬิกาอุปกรณ์ผิดจนถึงใช้คีย์ผิด และวิธีแก้แต่ละข้ออ่านคู่มือ →มือถือที่มีแอปยืนยันตัวตนหาย? ต้องทำอะไรมือถือที่มีรหัส 2FA หาย ถูกขโมย หรือถูกรีเซ็ต? วิธีกลับเข้าบัญชีด้วยคีย์ที่เก็บไว้ รหัสสำรอง การซิงก์คลาวด์ หรือการกู้คืนบัญชีอ่านคู่มือ →

คำถามที่พบบ่อย

Get2FA ฟรีไหม?

ฟรี และไม่ต้องสมัครสมาชิก เว็บไซต์อยู่ได้ด้วยโฆษณา ซึ่งไม่แสดงในตัวสร้างรหัส

รหัสตรงกับ Google Authenticator ไหม?

ตรงกัน ทุกแอปที่ใช้มาตรฐาน TOTP จะให้รหัสเดียวกันสำหรับคีย์เดียวกันในเวลาเดียวกัน รวมถึง Google Authenticator, Microsoft Authenticator, Authy และ 2FAS

ทำไมรหัสของฉันถูกปฏิเสธ?

สาเหตุที่พบบ่อยที่สุดคือนาฬิกาของอุปกรณ์ไม่ตรง รหัส TOTP ขึ้นกับเวลาที่แม่นยำ จึงควรเปิดวันที่และเวลาอัตโนมัติ ตรวจสอบด้วยว่าคัดลอกคีย์ครบ และเว็บไซต์ไม่ได้ใช้ 8 หลักหรือช่วงเวลา 60 วินาที (ดูการตั้งค่าขั้นสูง)

คุณเก็บคีย์ของฉันไหม?

ไม่ คีย์อยู่ในหน่วยความจำของแท็บนี้เท่านั้นและหายไปเมื่อปิดแท็บ เราไม่ใช้คุกกี้หรือพื้นที่เก็บข้อมูลสำหรับคีย์ มีเพียงธีมและตัวเลือกคัดลอกอัตโนมัติที่จำไว้บนอุปกรณ์ของคุณ

รับรหัสหลายบัญชีพร้อมกันได้ไหม?

ได้ วางบรรทัดละหนึ่งคีย์ หรือทั้งบรรทัดแบบ บัญชี|รหัสผ่าน|คีย์ คุณจะได้รหัสของแต่ละบรรทัดและรายการแบบ บรรทัด|รหัส เพื่อคัดลอกครั้งเดียว

คีย์ลับ 2FA คืออะไร?

คือรหัสสุ่ม ปกติยาว 16–32 ตัว ประกอบด้วยตัวอักษร A–Z และตัวเลข 2–7 (Base32) ที่เว็บไซต์แบ่งให้แอปยืนยันตัวตนตอนเปิดใช้การยืนยันแบบ 2 ขั้นตอน คิวอาร์โค้ดก็คือคีย์เดียวกันในรูปแบบภาพ

มือถือหาย Get2FA กู้รหัสให้ได้ไหม?

ได้เฉพาะเมื่อคุณเก็บคีย์ลับไว้ Get2FA อ่านคีย์จากอุปกรณ์อื่นไม่ได้ ถ้าไม่มีคีย์ ให้ใช้รหัสสำรองที่บริการให้ไว้ หรือขั้นตอนกู้คืนบัญชีของบริการนั้น
